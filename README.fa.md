# 📚 واژه‌یار (VajehYar) - تسلط بر واژگان و اصطلاحات انگلیسی

یک اپلیکیشن وب تعاملی و متمرکز، طراحی‌شده به‌طور اختصاصی برای فارسی‌زبانان جهت یادگیری **واژگان، اصطلاحات (Idioms) و عبارات کاربردی (Expressions)** زبان انگلیسی. این پروژه با استفاده از فناوری‌های مدرن وب ساخته شده تا تجربه‌ای روان، زیبا و بدون حواس‌پرتی را برای یادگیری فراهم کند.

## 🎯 هدف پروژه

هدف «واژه‌یار» تنها یک چیز است: **آموزش خالص واژگان، اصطلاحات و عبارات انگلیسی به فارسی‌زبانان.** 
در این پروژه خبری از آزمون‌های متفرقه (Trivia)، بازی‌های حاشیه‌ای یا محتوای غیرضروری نیست؛ فقط یک فرهنگ لغت تعاملی، دقیق و متمرکز بر یادگیری عمیق.

### حوزه‌های اصلی تمرکز:
1. 📖 **واژگان (Vocabulary)**: کلمات ضروری و پرکاربرد با ترجمه‌های دقیق فارسی.
2. 🦜 **اصطلاحات (Idioms)**: ضرب‌المثل‌ها و اصطلاحات رایج با درک مفهومی.
3. 💬 **عبارات کاربردی (Expressions)**: ترکیبات و جملات کوتاه روزمره برای مکالمه طبیعی.

## ✨ ویژگی‌ها

### 📚 فرهنگ واژگان جامع
- مرور واژگان و اصطلاحات به‌صورت الفبایی یا تصادفی.
- هر ورودی شامل موارد زیر است:
  - کلمه یا عبارت انگلیسی
  - تلفظ فونتیک (IPA)
  - ترجمه دقیق و روان به فارسی
  - جمله مثال کاربردی (با هایلایت کردن کلمه/اصطلاح هدف)
  - توضیح معنای جمله مثال به فارسی

### 🔍 جستجو و فیلتر هوشمند
- جستجوی آنی (Real-time) هم به زبان انگلیسی و هم فارسی.
- نمایش تعداد نتایج یافت‌شده.
- امکان فیلتر کردن بر اساس نوع محتوا: «واژه»، «اصطلاح» یا «عبارت».

### 🎲 حالت تمرین متمرکز
- دکمه «تصادفی» با انیمیشن روان برای مرور غیرمنتظره و تنوع در یادگیری.
- پیمایش مرحله‌ای (دکمه‌های بعدی/قبلی) برای یادگیری ساختاریافته و روزانه.
- رابط کاربری سازگار با کیبورد و پشتیبانی کامل از راست‌چین (RTL).

### 🎨 رابط کاربری تمیز و بدون حواس‌پرتی
- طراحی مدرن با گرادیانت‌های ملایم و رنگ‌بندی چشم‌نواز.
- انیمیشن‌های نرم و میکرواینترکشن‌ها برای بازخورد بصری بهتر.
- طراحی کاملاً واکنش‌گرا (Mobile-First) برای استفاده آسان در موبایل و دسکتاپ.
- بهینه‌سازی کامل چیدمان راست‌چین (RTL) برای خوانایی بهتر متون فارسی.

## 📦 نصب و راه‌اندازی

1. **کلون کردن مخزن**
```bash
git clone https://github.com/homayounmmdy/VajehYar
cd VajehYar
```

2. **نصب وابستگی‌ها**
```bash
npm install
# یا
yarn install
```

3. **اجرای سرور توسعه**
```bash
npm run dev
# یا
yarn dev
```

4. **مشاهده در مرورگر**
به آدرس [http://localhost:3000](http://localhost:3000) بروید.

## 🤝 مشارکت (Contributing)

این یک پروژه **متن‌باز (Open-Source)** است که منحصراً بر یادگیری لغوی تمرکز دارد. برای مشارکت:

### افزودن ورودی‌های جدید
1. مخزن (Repository) را فورک کنید.
2. واژگان، اصطلاحات یا عبارات جدید خود را به فایل `/public/data/lexicon.json` اضافه کنید.
3. ساختار JSON را حفظ کرده و مقدار `type` را به‌درستی تنظیم کنید.
4. یک درخواست ادغام (Pull Request) ارسال کنید.

### راهنمای مشارکت
- از ترجمه‌های فارسی دقیق، طبیعی و امروزی اطمینان حاصل کنید.
- جملات مثال باید واقعی، کاربردی و مرتبط با متن باشند.
- درج تلفظ فونتیک (ترجیحاً IPA) الزامی است.
- تمرکز پروژه صرفاً بر ارزش آموزشی است (از افزودن محتوای غیردرسی یا آزمون‌های متفرقه خودداری کنید).
